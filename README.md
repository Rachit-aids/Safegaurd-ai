# SafeGuard AI — by Rachit

PS-07: AI Safety, Hallucination Reduction & Jailbreak Defense Engine.

A GitHub Pages-ready hackathon prototype with:
- Prompt injection detection
- Jailbreak detection
- System prompt extraction detection
- Data exfiltration detection
- Risk scoring and ALLOW / REVIEW / BLOCK decisions
- Response grounding / hallucination-risk estimation
- Session analytics
- Responsive dashboard UI
- Animated security pipeline

## GitHub Pages

Keep `index.html`, `style.css`, and `script.js` in the repository root.

Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Note

This GitHub Pages build runs the prototype detection logic in the browser. It does not expose private API keys and does not require a Python server.

The scoring is a hackathon prototype heuristic, not a certified security or factuality guarantee.
